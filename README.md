# 🤖 AI Interview Platform

An AI-powered interview preparation platform built using the **MERN Stack**, Google AI APIs and Firebase Authentication. The platform dynamically generates interview questions based on the candidate's selected role and topics, evaluates responses and provides personalized feedback.

### ✨ Features

* 🤖 AI-generated technical and behavioral interview questions
* 🎯 Role-based and topic-based interview generation
* 📝 AI-driven candidate response evaluation
* 📊 Structured performance feedback and insights
* 💡 Improvement suggestions based on interview performance
* 🔐 JWT authentication and protected routes
* 🔥 Firebase Authentication
* 📚 Persistent interview history
* ⚡ RESTful APIs
* 📄 Pagination for large datasets
* 🗃️ MongoDB indexing for frequently accessed data
